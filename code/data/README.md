# Data Files

This folder mirrors the compact `code/data/` layout used by the original
FoodFlow GNN repository.

Included files:

- `FAF5_SCTG1.csv` through `FAF5_SCTG7.csv`: FAF-zone OD labels.
- `FAF_distance_matrix.csv`: FAF-zone distance matrix.
- `faf_features_aligned_filtered.csv`: FAF-zone node features.
- `county_aligned_filtered.csv`: county feature table retained for compatibility.

Large generated prediction outputs are not stored here.
